# ☁️ Módulo 3: Dando el salto a GitHub

¡Bienvenido al siguiente nivel! Hasta ahora, todo tu código vivía encerrado en tu ordenador. Si le pasaba algo a tu disco duro, perdías todo tu trabajo. 

En este módulo vamos a solucionar eso dando el salto a **Internet**. Aprenderás a conectar tu ordenador con GitHub para guardar copias de seguridad de tus proyectos, crear tu portafolio profesional y poder trabajar desde cualquier parte del mundo.

### 📖 Temario del Módulo

Haz clic en cada tema para acceder a la lección:

* **[Tema 1: Tu casa en la nube (Creando un repo en GitHub)](./01-creando-repo-en-github)**
  Aprende a preparar una "caja fuerte" vacía y segura en la web de GitHub para recibir tu código.

* **[Tema 2: El puente de conexión (`git remote`)](./02-el-puente-remote)**
  Construye el puente invisible que conectará la carpeta de tu ordenador con tu nuevo repositorio en la nube.

* **[Tema 3: Subiendo tus cambios (`git push`)](./03-subiendo-cambios-push)**
  El momento de la verdad. El comando mágico para enviar todo tu historial local a Internet y verlo publicado.

* **[Tema 4: Llevando tu código a todas partes (`git clone` y `git pull`)](./04-clonar-y-descargar)**
  Aprende a descargar tus proyectos en un ordenador nuevo o a traerte los últimos cambios para mantenerte siempre actualizado.

---

> **🏆 Objetivo del módulo:** Al finalizar estas lecciones, habrás dominado el ciclo de vida completo de un desarrollador profesional: crear código en local, subirlo a la nube para protegerlo, y descargarlo desde cualquier lugar.
