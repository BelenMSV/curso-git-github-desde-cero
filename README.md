# 🚀 Curso de Git y GitHub Desde Cero

¡Bienvenido/a al curso definitivo para dominar el control de versiones! 

Este es un curso interactivo, práctico y gratuito diseñado para que aprendas Git y GitHub desde la base absoluta hasta un nivel profesional. Aprenderás a crear tu primer repositorio, gestionar ramas, abrir Pull Requests, solucionar desastres y destacar tu perfil en la industria del software.

Si alguna vez has tenido miedo de borrar código por accidente o no entiendes cómo trabajan los equipos de programadores en el mundo real, **este curso es para ti.**

## 🎯 ¿Qué vas a lograr?
* Entender qué es Git y por qué es la herramienta número 1 exigida en las ofertas de trabajo.
* Dejar de guardar archivos como `proyecto-final-FINAL-ahorasi.zip`.
* Trabajar en equipo sin pisar el código de tus compañeros.
* Tener una "red de seguridad" para deshacer cualquier error o desastre en tu código.
* Aplicar las buenas prácticas y estándares que usan las empresas reales (GitHub Flow, Conventional Commits, etc.).

---

## 📚 Temario del Curso

El curso está dividido en 6 módulos progresivos. Haz clic en cada uno para acceder a las lecciones prácticas, comandos y ejemplos del mundo real:

* 📁 **[Módulo 1: Primeros pasos con Git](./01-primeros-pasos/README.md)**
  * *Aprende a instalar Git, configurar tu terminal y hacer tus primeros guardados (commits).*
* 📁 **[Módulo 2: Trabajando con Ramas (Branches)](./02-trabajando-con-ramas/README.md)**
  * *Descubre cómo crear universos paralelos en tu código para experimentar sin romper la versión principal.*
* 📁 **[Módulo 3: GitHub y el trabajo remoto](./03-github-y-trabajo-remoto/README.md)**
  * *Sube tu código a la nube, clona repositorios y conecta tu ordenador con el resto del mundo.*
* 📁 **[Módulo 4: Resolviendo Conflictos](./04-resolviendo-conflictos/README.md)**
  * *¿Qué pasa si dos personas editan la misma línea de código a la vez? Aprende a solucionarlo sin pánico.*
* 📁 **[Módulo 5: Deshaciendo errores (El arte de arreglar desastres)](./05-deshaciendo-errores/README.md)**
  * *Tu seguro de vida: aprende a usar `stash`, `restore`, `revert` y `reset` para salvar tu proyecto.*
* 📁 **[Módulo 6: Buenas Prácticas y Trucos Profesionales](./06-buenas-practicas/README.md)**
  * *Da el salto a nivel Senior: Conventional Commits, `.gitignore`, Git Aliases y la estrategia GitHub Flow.*

*(Nota: Asegúrate de revisar el README dentro de cada carpeta para seguir las instrucciones detalladas).*

---

## 🛠️ ¿Cómo usar este material?
1. **Sigue el orden:** Te recomiendo empezar por el Módulo 1 e ir avanzando secuencialmente. Cada concepto se apoya en el anterior.
2. **Practica:** No te limites a leer. Abre tu terminal y prueba cada comando que te enseñamos en los ejemplos. Git es pura memoria muscular.
3. **Equivócate:** ¡Es el mejor lugar para hacerlo! Tienes todo el Módulo 5 dedicado a deshacer errores, así que pierde el miedo a experimentar.
