# Tema 4: Tu Editor de Código (Visual Studio Code)

Git se encarga de vigilar y guardar el historial de tus archivos, pero... ¿dónde escribimos esos archivos? Necesitamos un **Editor de Código**.

Puedes usar el bloc de notas, pero nadie lo hace. El estándar absoluto de la industria hoy en día es **Visual Studio Code (VS Code)**, creado por Microsoft (los mismos dueños de GitHub). Es gratuito, ligero y muy potente.

## 🛠️ Instalación rápida
Si aún no lo tienes, descárgalo e instálalo desde [code.visualstudio.com](https://code.visualstudio.com/).

## 🤝 VS Code y Git: El equipo perfecto

VS Code está diseñado para trabajar mano a mano con Git y GitHub. Estas son las dos grandes ventajas que utilizaremos en este curso:

### 1. La Terminal Integrada
En lugar de tener una ventana para tu código y otra ventana negra separada para Git, VS Code tiene la terminal incrustada. 
* Solo tienes que ir al menú superior: `Terminal` -> `New Terminal` (o presionar `Ctrl + ñ` en español). 
* Desde ahí abajo podrás escribir todos tus comandos de Git (`git init`, `git add`, etc.) mientras ves tu código arriba.

### 2. Control de Versiones Visual
A medida que aprendas los comandos de Git en la terminal, te darás cuenta de que VS Code tiene un icono en su barra lateral izquierda (una especie de rama con circulitos) llamado "Source Control". 
A través de esa pestaña, VS Code te marcará con colores qué archivos has modificado, cuáles son nuevos y te permitirá hacer clics en lugar de escribir comandos. 

> **🎓 Nuestra filosofía:** En este curso primero aprenderás a hacerlo todo con comandos en la terminal (porque así entenderás de verdad cómo funciona Git). Una vez lo domines, ¡eres libre de usar los botones de VS Code para ir más rápido!
