# Tema 1: ¿Qué es Git y qué es GitHub?

Es muy común confundir ambos términos al principio cuando empezamos en el mundo de la programación, pero en realidad cumplen funciones totalmente distintas y se complementan.

## Git: Tu máquina del tiempo local

Git es el **motor**. Es un software de control de versiones que instalas en tu ordenador. 

Su trabajo es llevar un registro de todos los cambios que haces en tus archivos a lo largo del tiempo. Si te equivocas y rompes tu proyecto, Git te permite "viajar al pasado" y volver a una versión anterior que sí funcionaba.

## GitHub: Tu escaparate al mundo

GitHub es la **red social o la nube** para desarrolladores. Es una plataforma web de Microsoft donde subes los repositorios (proyectos) que gestionas con Git en tu ordenador.

Sirve para:
* Tener una copia de seguridad de tu código en internet.
* Colaborar con otras personas en el mismo proyecto.
* Mostrar tu trabajo al mundo (tu portfolio).

## 💡 La analogía definitiva

Para que no se te olvide nunca:

> **Git** es como la aplicación de la **cámara de fotos** de tu móvil (crea, edita y gestiona el contenido localmente en tu dispositivo).
> 
> **GitHub** es como **Instagram** (la plataforma web donde subes esas fotos, las respaldas y las compartes con la comunidad).
