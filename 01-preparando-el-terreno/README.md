# 🗺️ Módulo 1: Preparando el terreno

¡Empezamos la aventura! En este primer módulo vamos a sentar las bases. Antes de empezar a lanzar comandos mágicos, necesitamos entender qué herramientas vamos a usar, cómo funcionan y dejarlas listas en nuestro equipo.

Este módulo está dividido en 4 temas. Haz clic en cada uno de ellos para acceder a la lección:

### 📖 Temario del Módulo

* **[Tema 1: ¿Qué es Git y qué es GitHub?](./01-que-es-git-y-github)**
  Descubre la diferencia fundamental entre el "motor" (Git) y la "red social" (GitHub) y por qué necesitas ambos.

* **[Tema 2: Instalación y Configuración Inicial](./02-instalacion-y-configuracion)**
  Instala Git en tu sistema operativo (Windows, macOS o Linux) y preséntate formalmente para que Git sepa quién eres.

* **[Tema 3: Primeros pasos en la Terminal (Consola)](./03-basicos-de-la-terminal)**
  Pierde el miedo a la "pantalla negra". Aprende los 4 comandos básicos de supervivencia (`pwd`, `ls`, `mkdir`, `cd`) que usarás todos los días.

* **[Tema 4: Tu Editor de Código (Visual Studio Code)](./04-editor-de-codigo)**
  Prepara tu entorno de trabajo profesional. Descubre por qué VS Code es el mejor amigo de Git gracias a su terminal integrada.

---

> **🏆 Objetivo del módulo:** Al finalizar estas cuatro lecciones, tendrás tu ordenador perfectamente configurado y entenderás el entorno de trabajo necesario para empezar a crear tus propios repositorios.
