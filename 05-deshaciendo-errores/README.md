# Módulo 5: Deshaciendo errores (El arte de arreglar desastres)

¡Bienvenido al Módulo 5! Hasta ahora has aprendido a avanzar en tus proyectos, a crear ramas y a colaborar con otros. Pero seamos sinceros: la realidad del día a día de un programador está llena de errores, código roto y cambios de los que nos arrepentimos.

Aquí es donde Git brilla de verdad. En este módulo dejarás de ver a Git solo como un historial para guardar tu trabajo y empezarás a usarlo como tu mayor red de seguridad. Aprenderás a salir de cualquier apuro, desde un archivo borrado por accidente hasta un desastre que ya has subido a Internet.

## 📚 Índice del Módulo

* **[Tema 1: El baúl temporal (`git stash`)](./01-el-baul-temporal-stash/README.md):** Cómo guardar código a medias de forma segura cuando tienes una urgencia y necesitas cambiar de rama rápidamente.
* **[Tema 2: Borrón y cuenta nueva (`git restore`)](./02-borron-y-cuenta-nueva-restore/README.md):** Tu "goma de borrar" mágica para descartar cambios en un archivo antes de hacer commit.
* **[Tema 3: La máquina del tiempo segura (`git revert`)](./03-la-maquina-del-tiempo-segura-revert/README.md):** Cómo deshacer errores que ya están en GitHub creando un "anti-commit", sin desincronizar a tu equipo.
* **[Tema 4: Reescribiendo la historia (`git reset`)](./04-reescribiendo-la-historia-reset/README.md):** La herramienta definitiva (y más delicada) para borrar commits locales como si nunca hubieran existido.

## 🎯 Objetivos de aprendizaje

Al finalizar este módulo serás capaz de:

* Pausar tu trabajo actual sin perder el progreso ni romper otras ramas.
* Recuperar archivos a su último estado funcional en segundos.
* Revertir cambios públicos de manera profesional, colaborativa y segura.
* Limpiar y reorganizar el historial de tu ordenador antes de compartir tu código con el mundo.
