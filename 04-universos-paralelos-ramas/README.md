# Módulo 4: Universos Paralelos (Trabajando con Ramas)

¡Bienvenido al Módulo 4! Si hasta ahora Git te parecía una herramienta útil para guardar tu progreso, aquí es donde se convierte en un verdadero superpoder. 

En este módulo vamos a dejar de trabajar en una única línea de tiempo (`main`) y aprenderemos a crear "universos paralelos" o **ramas**. Esto te permitirá experimentar, crear nuevas funciones y romper el código todo lo que quieras con una red de seguridad absoluta, porque la versión oficial de tu proyecto seguirá intacta.

## 📚 Índice del Módulo

* **[Tema 1: Creando universos paralelos](./01-creando-universos-paralelos/README.md):** Aprende a crear ramas y a viajar entre ellas usando `git branch` y `git switch`.
* **[Tema 2: Uniendo los caminos](./02-uniendo-caminos-merge/README.md):** Descubre cómo fusionar tu trabajo experimental con la rama oficial usando `git merge`.
* **[Tema 3: Cuando los universos chocan](./03-resolucion-de-conflictos/README.md):** Pierde el miedo a los conflictos. Aprenderás a entenderlos y resolverlos paso a paso.
* **[Tema 4: Ramas en la nube y Pull Requests](./04-ramas-en-la-nube-y-pull-requests/README.md):** Lleva tus ramas a GitHub y aprende a colaborar en equipo con el flujo de trabajo profesional.

## 🎯 Objetivos de aprendizaje

Al finalizar este módulo serás capaz de:

* Trabajar en nuevas características sin miedo a romper el código principal.
* Unir el trabajo de diferentes ramas de forma segura.
* Mantener la calma y resolver conflictos de código como un profesional.
* Entender el ciclo de vida de una *Pull Request* en GitHub, la base del trabajo en equipo en la industria del software.
